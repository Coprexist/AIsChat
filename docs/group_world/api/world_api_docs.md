## AI 接入方式

1. 世界 AI 工具列表含 **`view_api_doc(section)`**（分区号 `01`~`09`），工具描述即上表（区名 + 区介绍）。
2. **先看区介绍再开区**，按需打开，不要一次全读。
3. 常用对应：建网页→03（必要时 06）；套 UI→04；群里说话→05；取通知→07；报错→08；写世界代码/受控接口→09。

## 快速上手（给 agent 的 6 步）

1. 了解身份与注入变量 → **01**
2. 写世界主页 → **03**（`file_write` 自动建目录）
3. 套现成 UI → **04**（list → view → apply）
4. 群里发言 → **05**（`send_group_message`，默认发到绑定群）
5. 用户改了代码 → **07**（对话开始先取通知）
6. 报错 → **08**
