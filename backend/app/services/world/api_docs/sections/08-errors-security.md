# 08 错误与安全

> 区介绍：错误体格式、状态码表、认证要求、写操作身份与防护约定。

## 1. 错误体格式（统一）

所有错误返回 JSON：

```json
{ "detail": "错误描述" }
```

工具调用失败时返回：
```json
{ "success": false, "error": "错误描述" }
```

**看到 `success: false` 就按 `error` 调整**，不要盲目重试同参数。

## 2. 状态码表

| 状态码 | 含义 | 常见场景 |
|--------|------|----------|
| 400 | 参数错误 / 越界路径 / 非法类型 | 路径含 `../`、文件类型不在白名单、参数缺失 |
| 401 | 未认证（token 缺失/过期） | 未登录、登录态过期 |
| 403 | 无权访问 | 非创建者、非群管理员/群主 |
| 404 | 世界/文件不存在 | 路径写错、世界被删 |
| 429 | 限流 | 请求过频，稍后重试 |
| 5xx | 服务端繁忙/异常 | 稍后重试 |

## 3. 认证要求

- 所有请求必须带 `Authorization: Bearer <JWT>`。
- 实例收到任何 API 请求**第一件事就是验证用户信息**（JWT），世界代码的写操作**以触发它的用户/AI 身份执行，不可伪造**。

## 4. 防护约定（平台侧已强制，你无需实现）

| 防护 | 说明 |
|------|------|
| 路径越界 | 世界文件只允许在 `data/worlds/{id}/` 内，`../`、绝对路径、符号链接逃逸一律拒绝 |
| 类型白名单 | 文件写入只允许白名单扩展名（见 03 分区），危险类型拒绝 |
| 大小上限 | 单文件 5MB |
| 身份校验 | 群管理操作（改角色/踢人）仅群主/管理员可调用 |
| 管理权限 | `set_group_member_role` 仅群主；`kick_group_member` 群主/管理员，不能踢自己/群主 |

## 5. LLM 友好错误（世界对话层）

世界 AI 对话遇到 API 错误时，系统会转成友好提示：

| 场景 | 提示方向 |
|------|----------|
| 402 余额不足 | 引导充值（已记录工作流，充值后说「继续」可接着做） |
| 401/403 密钥问题 | 提示换 Key |
| 429 限流 | 稍等重试 |
| 5xx | 服务繁忙，稍后重试 |

**你该做的**：遇到 402 时向用户说明"余额不足，充完说继续"；其他错误如实转述并给出下一步。

## 6. 工具使用纪律

1. **别把工具调用原始内容写进回复文本**——直接说你要做什么/做了什么。
2. **先读后写**：改文件先 `file_read`，群聊先 `get_group_messages`，管理先 `list_group_members`。
3. **温和去重**：重复调用同一工具且结果一致会被提示「⏭ 已跳过」——那是系统在帮你省 token，不是错误；结果变了会正常返回。
4. **工作流记忆**：对话中断（无最终回复）时，系统记录已完成工具；下次对话会注入【未完成工作流】提示，说「继续」即可接着做，不要重做。
